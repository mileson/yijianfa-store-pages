## ✨ 核心特性

- **产品说明。** index.html 保留扩展产品的公开介绍入口。
- **支持与隐私。** support 与 privacy 分别保存用户支持和隐私说明页面。
- **静态托管。** 内容、图片和样式按现有静态页面方式维护。

## ✅ 适用场景

适合维护一键发 Chrome Web Store 审核资料的开发者。

## 🚀 快速开始

从 [`index.html`](index.html) 查看站点入口。修改页面或资源后，检查页面内链接、图片和样式，再沿用现有静态托管方式部署。

## 🧩 模块速查

按要处理的工作选择入口，先看模块职责，再进入对应文件或目录。

| 模块入口 | 负责什么 | 什么时候看 |
| --- | --- | --- |
| [`index.html`](index.html) | 静态站点入口 | 查看页面结构、内容与资源引用 |
| [`privacy/`](privacy/) | 隐私政策页面 | 维护隐私说明与对应页面 |
| [`support/`](support/) | 帮助与支持页面 | 维护用户支持内容与入口 |
