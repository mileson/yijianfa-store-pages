帮助与支持

从安装、开始使用到问题排查，都可以在这里找到。提交反馈前，请遮挡账号、邮箱、验证码和其他私人信息。

安装扩展

  1. 在 Chrome 地址栏打开 chrome://extensions。
  2. 打开页面右上角的“开发者模式”。
  3. 点击“加载已解压的扩展程序”，选择一键发扩展目录。
  4. 将一键发固定到工具栏，点击图标打开工作台。

开始使用

  1. 先在浏览器中登录准备发布的平台。
  2. 打开一键发，选择内容类型并准备内容和素材。
  3. 新建或选择发布组合，本次不需要的平台可以临时移除。
  4. 点击“一键填入”，等待所选平台发布页打开并完成内容填入。
  5. 逐页检查文字、图片、视频和平台设置，再由你确认是否发布。

常见问题

没有打开平台页面

确认已经选择发布组合，并检查 Chrome 是否拦截了新标签页。还要确认一键发账号当前可用，页面没有显示登录或额度提示。

页面打开了，但内容没有填入

先确认该平台已经登录，再刷新页面重试。内容平台改版可能让原有填写位置失效；如果问题持续出现，请记录平台名称、内容类型和操作步骤。

为什么填入后还要自己确认

这是产品默认的安全边界。一键发负责减少打开页面和重复填写，最终发布前的内容、账号和平台设置仍需要你确认。

隐私与安全边界

  • 使用你已经在 Chrome 中建立的平台登录状态，不保存平台账号密码。
  • 准备发布的文字、图片和视频在浏览器与本机处理。
  • 默认只填入内容，不替你跳过平台的最终确认。
