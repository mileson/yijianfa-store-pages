一键发隐私政策

更新日期：2026 年 8 月 11 日。本政策说明“一键发”Chrome 扩展、可选的本地 CLI 及同源会员服务如何处理数据。

1. 我们处理哪些数据

一键发账号与会员数据

当你登录一键发时，我们会处理邮箱地址、邮箱验证码、会话令牌、账号创建与最近登录时间、会员状态、邀请关系，以及你主动发起的会员订单或兑换记录。验证码和会话令牌在服务端以不可直接还原的摘要保存。

发布额度记录

为了判断普通用户的月度使用次数，我们会记录一次操作的随机请求编号、操作类型（填入或发布）、完成状态、成功处理的平台数量和时间。我们不会在一键发会员服务器保存这次操作的正文、图片或视频。

匿名使用情况

为了改进产品体验和判断功能是否稳定，我们会记录固定目录内的使用事件。事件只包含随机匿名标识和会话标识、事件时间、内容类型大类、所选平台枚举、填入或发布模式、处理结果，以及平台数量和耗时档位。

这些使用事件不包含邮箱、验证码、会话令牌、Cookie、标题、正文、图片或视频、素材与文件名、完整网址、来源网址及其查询参数、平台账号、邀请码、订单号、IP 地址、User-Agent、DOM 或屏幕回放，也不包含自由格式的错误消息或调用堆栈。

扩展与会员网页本地数据

扩展会在你的浏览器本地保存发布组合、平台选择、功能设置、一键发登录会话，以及用于显示登录状态的平台账号名称、头像或可发布范围。扩展和会员网页的匿名使用事件在网络暂时不可用时会分别进入最多 200 条、最长保留 7 天的本地待发送队列。

CLI 本地数据

安装 CLI 时，本机会保存当前扩展编号、本机桥配置和 CLI 版本。你交给 CLI 的正文和素材路径只用于本次本地任务；CLI 不读取或保存一键发会员令牌、平台 Cookie 或账号密码。

你准备发布的内容

文字、图片、视频、导入的网页正文和平台页面内容在浏览器及你的电脑本地处理，并按你的操作填入或发送到你选择的平台。

2. 为什么需要这些数据

  • 完成邮箱验证、保持登录并展示会员状态；
  • 执行普通用户额度判断；
  • 了解常用功能、处理耗时和失败环节；
  • 保存和恢复发布组合、平台设置与账号显示状态；
  • 按你的选择打开平台发布页、导入网页内容并完成内容填入；
  • 处理会员购买、兑换、邀请奖励和相关售后问题；
  • 防止滥用、排查故障并保障服务安全。

3. 数据会发送到哪里

  • 你的电脑与 Chrome：CLI 和扩展通过当前用户可访问的本机连接交换任务、状态和临时素材地址。
  • 一键发服务：接收邮箱登录、会员、发布额度和上述匿名使用事件所需的最少数据，不接收你准备发布的正文、图片或视频。
  • 你选择的内容平台：扩展使用你在浏览器中已经建立的平台登录状态读取账号信息，并把内容填入或发送到相应平台。
  • 你主动配置的服务：只有在你配置并选择 webhook 或自建站点时，扩展才会向该地址发送内容。
  • 支付与邮件服务：相应服务商会处理完成支付或邮件投递所需的数据，并适用其自身隐私规则。

一键发不会出售用户数据，也不会将数据用于广告画像、信用评估或与核心功能无关的用途。

4. 权限使用说明

  • storage：在浏览器本地保存组合、设置、登录会话和任务状态摘要。
  • tabs / tabGroups：打开并整理一次操作涉及的平台标签页。
  • clipboardWrite：在你触发导入、复制或填入时写入剪贴板。
  • nativeMessaging：只在你安装 CLI 后连接一键发本机桥。
  • 网站访问权限：在你使用的平台页面识别登录状态、填入内容；扩展不会把浏览历史上传到一键发服务器。

5. 保存、安全与删除

匿名使用事件在服务端默认保留 180 天，并按此期限执行清理；本地待发送队列分别最多保留 200 条、最长保留 7 天。账号、会员、额度和售后记录仅在提供对应服务所需的期限内保留。我们采取访问控制、摘要存储和传输加密等措施。

运行 yijianfa uninstall-host 可移除本机桥配置，卸载 CLI 可移除程序；卸载扩展会移除 Chrome 管理的扩展数据。需要查询或删除一键发账号的服务端数据时，请通过 Chrome Web Store 商品页的支持入口联系开发者。

6. 政策更新与联系

功能或数据处理方式发生重要变化时，我们会更新本页面的日期和内容。对本政策或数据处理有疑问，可通过帮助与支持页面联系开发者。
